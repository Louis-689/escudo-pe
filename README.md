# Escudo 🛡️

**Protección, pruebas y denuncia para víctimas de extorsión en el Perú. Cifrado y sin internet.**

Escudo ayuda a quien recibe amenazas de extorsión a **protegerse a sí mismo y a su familia, registrar cada amenaza, conservar las pruebas sin que se alteren y llegar a la comisaría con un informe ordenado**. Funciona en cualquier celular con navegador, sin internet y sin crear cuentas. Todo queda **cifrado y solo en el teléfono** de la víctima.

> Escudo no reemplaza la denuncia ni la asesoría legal. Si estás en peligro ahora mismo, llama al **105**.

---

## ¿Por qué existe?

La extorsión es el delito que más crece en el Perú:

- La Fiscalía registró **13 892 denuncias de extorsión entre enero y julio de 2026** y proyecta unas **32 000 al cierre del año**. Fueron unas 11 000 en 2022 y 27 500 en 2025 ([América TV, 03/09/2026](https://www.americatv.com.pe/noticias/actualidad/fiscalia-reporta-14-mil-casos-extorsion-2026-n522272)).
- Más de **60 choferes asesinados** en lo que va de 2026, según la PNP ([Caretas](https://caretas.pe/?p=829452)).
- **9 de cada 10 peruanos se sienten inseguros**, y la extorsión es el segundo delito que más temen ([Gestión / Ipsos, 31/03/2026](https://gestion.pe/peru/nueve-de-cada-10-peruanos-se-sienten-inseguros-los-delitos-de-mayor-riesgo-noticia/)).
- La Policía pide a las víctimas **"grabar y conservar los mensajes"** y denunciar cuanto antes ([El Peruano](https://www.elperuano.pe/noticia/216147-campana-yo-no-caigo-en-la-extorsion-yo-denuncio-revisa-estas-recomendaciones)). En la práctica, muchas pruebas se pierden: chats borrados, celulares cambiados, capturas sin fecha y números anotados en papeles.

No existía una herramienta abierta, gratuita y pensada para el Perú que ayudara a la víctima en ese momento. Escudo cubre ese vacío.

## Qué hace

### Protegerte

| Función | Para qué sirve |
| --- | --- |
| **Botón SOS** | Siempre visible, incluso sin contraseña. Llama al 105 o, con un toque, prepara un mensaje de alerta con **tu** ubicación GPS para tus contactos de confianza por WhatsApp o SMS (a uno o a cada uno). Solo tienes que pulsar "Enviar". |
| **Aviso de trayecto** | Antes de ir a un cobro, una reunión o abrir el negocio, avisas a un contacto a dónde vas y hasta qué hora debe saber de ti. Si no le escribes "Llegué bien", da la alarma, aunque te quiten el celular. |
| **Plan de seguridad** | Lista práctica para la familia, las rutinas, la casa o el negocio y la denuncia, con avance guardado y cifrado. |
| **Palabra clave familiar** | Una palabra que solo tu familia sabe, para desarmar el "tenemos a tu hijo" de una llamada falsa. Se guarda cifrada. |
| **Blindaje digital** | Pasos concretos para cerrar WhatsApp, llamadas, Facebook, Instagram, TikTok y el celular: la información que los extorsionadores usan para presionarte. |
| **Ayuda legal y psicológica** | ALEGRA 1884 (abogados gratis del Estado), Línea 113 (apoyo psicológico gratuito 24 h) y cómo pedir medidas de protección a la Fiscalía. |

### Reunir pruebas y denunciar

| Función | Para qué sirve |
| --- | --- |
| **Registrar amenazas** | Fecha y hora, canal (llamada, WhatsApp, SMS, redes, en persona, carta), número o perfil, monto exigido, Yape/Plin/cuenta indicada, mensaje literal y descripción. |
| **Importar chat de WhatsApp** | Elige el chat exportado (.zip o .txt con sus archivos) y cada mensaje del extorsionador queda registrado con su número, fecha, hora y fotos o audios. Funciona con Android y iPhone, en español e inglés. |
| **Datos detectados** | En cada mensaje, Escudo detecta números (y su país), cuentas bancarias, CCI, Yape/Plin, billeteras de criptomonedas, enlaces, perfiles, correos, placas de vehículos, montos y señales de riesgo (amenazas de muerte, explosivos, familia, armas, plazos). |
| **Datos para la Fiscalía** | El informe agrupa cada número y cuenta con cuántas veces aparece, la primera y última fecha y el canal: justo lo que se necesita para pedir, con orden judicial, la identificación de titulares, el registro de llamadas, la geolocalización y el levantamiento del secreto bancario. |
| **Cadena de custodia** | Cada verificación, informe, paquete, copia o importación queda registrada en la bitácora encadenada, con fecha y hora. El informe incluye espacio para marca, modelo e IMEI del celular. |
| **Guardar pruebas** | Capturas, audios, videos, fotos o PDF, cifrados dentro del teléfono. |
| **Grabar audio** | Graba desde la misma app (por ejemplo, una llamada en altavoz o lo que recuerdas justo después). |
| **Huella de cada prueba** | Calcula el SHA-256 del archivo al registrarlo. Si luego el original da la misma huella, no fue modificado. |
| **Bitácora encadenada** | Cada registro guarda la huella del anterior. Editar, borrar o reordenar algo rompe la cadena y se detecta. Las correcciones se agregan como notas, sin tocar el original. |
| **Informe para la denuncia** | Resumen (números y cuentas que se repiten, monto máximo, fechas) y detalle cronológico. Se imprime, se guarda como PDF, se copia como texto o se comparte. |
| **Paquete de pruebas (ZIP)** | Un solo archivo para la comisaría o el abogado: pruebas originales, informe, `huellas.sha256` y la bitácora completa. Se verifica con `sha256sum -c huellas.sha256`. |
| **Comprobar un archivo** | Eliges una captura o audio y Escudo te dice si es exactamente una de las pruebas registradas. |
| **Guía y contactos** | Qué hacer paso a paso y a quién llamar (111, 105, 1818, Dirincri, ALEGRA 1884, Línea 113), con fuente y fecha de verificación. Se puede ver sin abrir la bitácora. |
| **Salida rápida** | Un botón cierra la app y abre una página inofensiva. La bitácora se bloquea sola si la app queda 2 minutos en segundo plano. |
| **Modo camuflado** | Cerrada, la app parece una libreta de "Notas". Se abre escribiendo la contraseña en "Buscar"; cualquier otra cosa muestra "No se encontraron notas". |
| **Copia de seguridad** | Archivo cifrado para guardar en otro teléfono de confianza. Sin la contraseña no sirve. |
| **Sin internet** | Después de la primera visita funciona sin conexión (PWA). Se puede "instalar" en la pantalla de inicio. |

## Lo que Escudo no hace (y por qué)

Escudo **no rastrea la IP, la ubicación ni la identidad** de quien llama o escribe:

- **No es técnicamente posible** desde una app: una llamada o un mensaje de WhatsApp no le muestran al receptor la IP ni la ubicación de quien lo envía. Las herramientas que lo prometen dependen de engañar al extorsionador para que abra un enlace trampa, lo que expone a la víctima a represalias.
- **Es ilegal sin orden judicial** y puede invalidar las pruebas del caso.
- **Una página web no puede enviar SMS ni WhatsApp sola.** El SOS y el aviso de trayecto dejan el mensaje listo y abren la app; la persona pulsa "Enviar". Así nadie puede usar Escudo para mandar mensajes en tu nombre.
- **Aún no hay una lista comunitaria de números extorsivos.** Necesitaría un servidor central (que guardaría datos de víctimas) y los números se falsifican con facilidad, así que una lista abierta podría marcar a inocentes. Queda como idea para cuando exista un aliado institucional que la administre.
- **La identificación la hace la Policía y la Fiscalía con orden judicial**: geolocalización (D. Leg. 1182), intervención de comunicaciones (Ley 27697 y art. 230 del Código Procesal Penal) y, desde enero de 2026, un trámite de 24 horas en casos de extorsión (D. Leg. 1708, [Caretas](https://caretas.pe/?p=787847)). Escudo le entrega a la víctima, ordenados, los datos que la Fiscalía necesita para pedirlo rápido ([modelo de solicitud](https://modelo.pe/solicitud-al-fiscal-de-geolocalizacion-y-levantamiento-del-secreto-de-las-comunicaciones-del-numero-extorsionador/)).

## Privacidad y seguridad

- **No hay servidor.** Escudo es una página estática. Nada de lo que escribes sale del teléfono, salvo que tú descargues o compartas el informe o la copia.
- **Cifrado:** la clave se deriva de tu contraseña con PBKDF2-SHA256 (210 000 iteraciones) y los datos se cifran con AES-GCM de 256 bits, usando la Web Crypto API del navegador. No hay dependencias externas.
- **Política de seguridad de contenido estricta:** la app no carga scripts de terceros ni puede enviar datos a otros dominios.
- **Si olvidas la contraseña, nadie puede recuperar los datos.** Es a propósito.

**Límites que debes conocer** (más detalle en [SECURITY.md](SECURITY.md)):

- Si alguien tiene tu celular **desbloqueado y con Escudo abierto**, puede ver la información. Usa la salida rápida y el bloqueo automático.
- Una contraseña corta puede adivinarse con tiempo si alguien copia los datos del teléfono. Usa una frase larga.
- La huella prueba que un archivo **no cambió desde que se registró**, no quién lo envió. No reemplaza el peritaje: **no borres los originales** de tu celular, la Policía puede pedirlos.
- Borrar los datos del navegador borra la bitácora. Haz copias de seguridad.
- El **paquete de pruebas (ZIP) no está cifrado**, porque está hecho para entregarlo. Bórralo de tu celular después de entregarlo.
- El modo camuflado engaña a una mirada rápida, no a alguien que revise el navegador a fondo.
- Para que el SOS funcione sin contraseña, **los nombres y números de tus contactos de confianza** (y la hora límite de un trayecto en curso) se guardan sin cifrar. Usa apodos si prefieres. El destino del trayecto, el plan de seguridad y la palabra clave sí van cifrados.

## Cómo usarlo

1. Abre la app desde el navegador del celular (Chrome, Firefox, Samsung Internet, Safari).
2. Crea una contraseña.
3. Cada vez que recibas una amenaza, entra a **Registrar**, llena lo que sepas y adjunta las capturas o audios. Si te escriben por WhatsApp, usa **Importar un chat de WhatsApp**.
4. Antes de ir a la comisaría, entra a **Informe** → *Comprobar que nada fue alterado* → *Ver informe para imprimir o guardar en PDF*, o descarga el *paquete de pruebas*.
5. Ve a la comisaría o al Depincri con el informe **y con tu celular**.
6. Si temes que revisen tu celular, activa el **modo camuflado** en Ajustes.

## Probarlo en tu computadora

Requiere [Node.js](https://nodejs.org/) 20 o superior. No hay que instalar dependencias.

```bash
git clone https://github.com/Louis-689/escudo-pe.git
cd escudo-pe
npm start        # abre http://localhost:8080
npm test         # corre los tests
```

> El cifrado del navegador solo funciona en `https://` o en `localhost`. Si abres `index.html` directamente como archivo, no funcionará.

## Publicarlo gratis (GitHub Pages)

El repositorio incluye `.github/workflows/pages.yml`. En GitHub ve a **Settings → Pages → Source: GitHub Actions**. Cada cambio en `main` corre los tests y publica la app en `https://<tu-usuario>.github.io/escudo-pe/`.

Cualquier persona u organización (municipalidad, gremio de transportistas, asociación de bodegueros, ONG) puede publicar su propia copia en su dominio.

## Estructura

```
index.html            Interfaz (una sola página)
css/app.css           Estilos (modo claro y oscuro, pensado para pantallas pequeñas)
js/app.js             Lógica de la interfaz
js/core/crypto.js     Cifrado y huellas (Web Crypto)
js/core/model.js      Validación, normalización, cadena de huellas y resumen
js/core/vault.js      Bóveda cifrada: crear, abrir, agregar, verificar, copias
js/core/storage.js    IndexedDB (navegador) y memoria (tests)
js/core/report.js     Informe en texto y HTML
js/core/evidence.js   Paquete de pruebas (ZIP) y búsqueda por huella
js/core/indicators.js Detección de números, cuentas, enlaces, placas y riesgos
js/core/whatsapp.js   Lectura de chats exportados de WhatsApp
js/core/unzip.js      Lector de ZIP (para el chat exportado en iPhone)
js/core/zip.js        Generador de ZIP sin dependencias
js/core/safety.js     SOS, aviso de trayecto, plan de seguridad y blindaje digital
js/data/contacts.js   Contactos oficiales y pasos a seguir (con fuentes)
sw.js                 Service worker para uso sin internet
tests/                Tests con node:test (sin dependencias)
```

Todo es JavaScript sin compilar ni dependencias, para que cualquiera pueda auditarlo.
